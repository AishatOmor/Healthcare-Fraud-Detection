# Upload guide

1. Unzip this package.
2. Open your existing GitHub Healthcare-Fraud-Detection repository.
3. Upload the contents of the unzipped folder (not the parent folder) or commit using Git.
4. Replace the old root README with this package’s `README.md`. The old scripts and plots are preserved under `legacy_original/`.
5. Do not upload Kaggle raw data, trained models, or personal/real patient information.
6. Verify the Excel dashboard downloads correctly from GitHub. GitHub may not preview all Excel features.
7. Before making the repository public, confirm redistribution rights and review the pseudonymous provider IDs in the dashboard.

This ZIP is a prepared portfolio package, not a GitHub upload performed by ChatGPT.
